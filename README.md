## Sobre o projeto

O MenteSã é uma plataforma web voltada para profissionais de Psicologia e Nutrição, com o objetivo de facilitar o agendamento e o gerenciamento de consultas.

A aplicação permite cadastrar, visualizar, pesquisar, editar e excluir consultas, organizando informações como paciente, profissional, especialidade, data, horário e modalidade de atendimento.

O projeto busca centralizar essas informações em um único ambiente, tornando a organização dos atendimentos mais prática e eficiente.
